# Docker Compose and Containers

Students have a container runtime installed on their machines, and use a tool like Docker Compose to start a local developer environment on their own machines.

Have a container runtime (Podman, Docker desktop, whatever)\

A script, or a "docker compose" file that will start up all these "backing services"

## Advantages

- nimble, relatively easy
- can have multiple versions (more on this later)

## Disadvantages

- a bit challenging to learn, setup
- can be a bit flaky - and a bunch of stuff you are writing that doesn't go to production
    - flaky - can restart easily, but it's a pain.
