# Kubernetes / Redhat OpenShift Local

Create a local environment using the configuration (deployments, services, etc.) that your app will use in all other environments.

## Advantages

- Closer to production (dev/prod parity)
- More resilient
- The manifests (deployment files) are the same as you'd use in other environments.

## Disadvantages

- More intensive
- I don't think you can do this.
