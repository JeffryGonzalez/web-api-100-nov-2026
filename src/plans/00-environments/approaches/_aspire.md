# Use Aspire

Use Microsoft's Aspire tool for creating a development environment. 

## Advantages

- Super easy
- allows access to otel data
- has a groovy dashboard
- don't need to learn container details (and has integrations)
- Can use to "publish" your app*

## Disadvantages

- A bit to learn, still easier than the other ones.
- Publish is still a bit weak - unless you are publishing to Azure. ;)
